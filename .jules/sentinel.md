## 2025-02-23 - [XSS via Telegram Parse Mode]\n**Vulnerability:** User inputs were being directly injected into a Telegram message payload using `parse_mode: 'HTML'` in `api/save-lead.js`.\n**Learning:** Telegram API throws an error and rejects the message if an HTML tag is invalid or if special characters like `<`, `>`, or `&` are not properly escaped in HTML parse mode. This not only causes an HTML Injection/XSS vector in clients rendering the payload but also acts as a Denial of Service by making the notification API fail.\n**Prevention:** Always use an `escapeHTML` utility function or sanitize inputs prior to constructing HTML strings, or consider omitting `parse_mode` entirely to rely on raw plain-text sending when formatted rich-text is not strictly necessary.
