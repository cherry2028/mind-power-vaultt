## 2025-02-14 - HTML Injection in Telegram Message Payload
**Vulnerability:** Found HTML Injection vulnerability in Telegram bot messaging endpoint (`api/save-lead.js`). User input (`name`, `phone`, `experience`, `profile?.primaryPattern`) was directly interpolated into a Telegram message string that was sent with `parse_mode: 'HTML'`, which could allow malicious users to inject unescaped HTML tags that could cause message delivery failures or format corruption.
**Learning:** When using `parse_mode: 'HTML'` in the Telegram API, ANY user input must be rigorously sanitized. Unescaped characters like `<` and `>` will be treated as HTML tags, and since Telegram only supports a very limited set of tags, invalid tags will cause the entire API request to fail.
**Prevention:** Always use an `escapeHTML` helper function to sanitize user-controlled strings before injecting them into a Telegram message payload with `parse_mode: 'HTML'`. Alternatively, if formatting is not strictly needed, simply omit `parse_mode` to send absolute plain text.
