## 2026-07-01 - [Admin Auth Bypass via Hardcoded Frontend Password]\n**Vulnerability:** The admin login mechanism used a hardcoded password check directly in the frontend component `src/App.jsx` (`if(adminPwdInput===ADMIN_PWD)`). The password itself was embedded in the client bundle via `VITE_ADMIN_PASSWORD`.\n**Learning:** Relying on client-side authentication and exposing secrets (even if prefixed with `VITE_`) makes it trivial for attackers to bypass authentication by reading the JavaScript bundle.\n**Prevention:** Authentication must always happen on the backend. Move sensitive credential verification to an API endpoint (e.g., `/api/validate-code`) and never use `VITE_` to expose backend secrets.
