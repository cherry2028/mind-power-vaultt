## 2025-02-28 - Unescaped HTML Interpolation Vulnerability (Email Injection / Telegram DoS)
**Vulnerability:** User-controlled inputs (`name`, `report` values) were directly interpolated into raw HTML payloads for Resend (Email) and sent with `parse_mode: 'HTML'` to Telegram (in `api/notify.js` and `api/save-lead.js`).
**Learning:** Directly interpolating user-controlled strings into email HTML bodies can lead to Email HTML Injection, where an attacker might inject malicious formatting, links, or phishing payloads. Additionally, Telegram's API is very strict about unclosed or malformed HTML tags when using `parse_mode: 'HTML'`, which can easily lead to Denial of Service (message dropping) if special characters (`<`, `>`, `&`) are present in user input.
**Prevention:** Always escape user-controlled variables before interpolating them into HTML strings sent via email. For Telegram, either send absolute plain text or rigorously escape all user inputs (`<`, `>`, `&`, `"`) to prevent parsing errors.
