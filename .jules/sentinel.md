## 2024-05-31 - [Security] Prevent Client-Side Leakage of Secrets
**Vulnerability:** Client-side source files (`src/App.jsx` and `src/utils/api-client.js`) exposed `ADMIN_PWD` directly as hardcoded credentials (or through environment variables that fallback to hardcoded) and `VITE_INTERNAL_API_KEY`, leaking them to users browsing the frontend code.
**Learning:** Putting any credentials (such as password backups or API keys) in Vite environment variables or hardcoding them inside frontend code exposes them completely. Public endpoints do not need API key security checks, and login verification must exclusively be done server-side.
**Prevention:** Never use hardcoded keys or passwords in the frontend bundle. Ensure authentication (like admin logins) is pushed completely to a backend endpoint (`/api/validate-code`) that can safely verify and return an auth token or boolean result securely. Furthermore, do not implement server-side validation using keys intended to be hidden if the keys must be sent directly from public frontend requests.
