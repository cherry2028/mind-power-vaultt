## 2025-02-14 - [Hardcoded Telegram Secrets in Frontend]
**Vulnerability:** Hardcoded `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, and internal api key `mpv_secure_api_key_2026` were discovered directly embedded inside the client-side component `src/App.jsx`.
**Learning:** These variables allowed direct communication with a sensitive Telegram API right from the user's browser, completely bypassing the backend which possessed the same capabilities via `api/notify.js`. Exposing the secrets on the frontend would allow anyone viewing the source to extract the bot token and impersonate the bot or spam the designated chat ID. Additionally, the fallback code to notify the backend leaked an internal secure API key as a hardcoded string.
**Prevention:** Always delegate interactions with third-party APIs that require sensitive authorization tokens (like Telegram bots) to backend endpoints. Utilize environment variables (e.g. `VITE_INTERNAL_API_KEY`) accessed via `getEnv` instead of hardcoding internal security strings.
